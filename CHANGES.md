# Правки относительно исходника (ferscalone/bend_stand)

Изменён только `src/EncoderTracker.cpp`. Всё остальное — как в оригинале.

## 1. `encoder_.begin(4)` → `encoder_.begin()`
`4` передавался в библиотеку AS5600 как номер **аппаратного DIR-пина**
(`begin(uint8_t directionPin)`), а не как пин I2C. На стенде DIR-пин физически
не разведён (только I2C), и библиотека в этом случае должна вызываться без
аргумента (программный режим направления). Хуже: GPIO4 — это `PIN_STEP_P`
(импульс ШАГ мотора) в `Config.h`, и AS5600.begin(4) сама дёргала pinMode/digitalWrite
на этом пине — конфликт с шаговым мотором.

## 2. Реальная проверка подключения энкодера
Раньше `EncoderTracker::begin()`/`update()` проверяли `raw > 4095`, а это
никогда не срабатывает: `rawAngle()` в библиотеке всегда маскирует результат
в 0..4095, даже при полностью нерабочей шине I2C (возвращает 0). Из-за этого
`begin()` возвращал `true`, даже если энкодер не отвечает физически — отсюда
"контроллер не видит энкодер" без вменяемой ошибки в логе.

Теперь используется настоящий код ошибки I2C: `encoder_.begin()` (проверяет
ACK на шине) + `encoder_.lastError() != AS5600_OK` после каждого чтения угла.

## 3. Добавлено сканирование шины I2C при старте
При инициализации энкодера в Serial (115200) печатается, какие адреса
ответили на шине и на каких пинах (SDA/SCL из `Config.h`). Если ничего не
найдено — печатается явная подсказка проверить проводку/питание/подтяжки.
AS5600 по умолчанию должен быть на адресе `0x36`.

## Если пины энкодера у вас физически не 18 (SDA) / 17 (SCL)
Это два `constexpr` в начале `src/Config.h`:
```cpp
constexpr uint8_t PIN_AS5600_SCL = 17;
constexpr uint8_t PIN_AS5600_SDA = 18;
```
Поменяйте под свою распайку и пересоберите — больше нигде эти номера не
задействованы. Проверить, что реально нашлось на шине, можно по логу
сканирования, которое теперь печатается при старте.

## Сборка
Как в README проекта:
```
pio run                 # сборка
pio run -t upload       # сборка + прошивка
pio device monitor      # серийный монитор, 115200
```
Библиотеки (AS5600, AsyncTCP, ESPAsyncWebServer) подтянутся сами по
`lib_deps` из `platformio.ini`.
